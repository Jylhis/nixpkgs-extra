# Security policy

## Reporting a vulnerability

Report it privately through GitHub: on the repository's **Security** tab,
choose **Report a vulnerability**. Please don't open a public issue.

## Scope

In scope: the package definitions, overrides, NixOS and Home Manager modules,
and the CI workflows in this repository, for example a module that exposes a
service or a credential it shouldn't, or a package fetched from an unverified
source.

A vulnerability in the upstream software itself belongs to that project. If
a fix exists upstream and the package here lags behind, a report or a pull
request with the update is welcome.
